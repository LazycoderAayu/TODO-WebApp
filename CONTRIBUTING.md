# Contributing to Todo-App ✅

This is the ultimate productivity invention. If you want to help make task management even more efficient, follow these rules.

---

## How to Contribute

### 1. Reporting Bugs
- Check the Issues tab before reporting.
- Provide clear steps to reproduce the bug (e.g., "Delete button not working on mobile").

### 2. Feature Requests
- Ideas for Dark Mode, Drag-and-Drop, or LocalStorage sync? Open an issue with the "enhancement" tag.

### 3. Pull Requests
1. Fork the repository.
2. Create your branch: `git checkout -b feature/CoolNewTaskFeature`
3. Commit your logic: `git commit -m 'Added priority labels to tasks'`
4. Push the branch: `git push origin feature/CoolNewTaskFeature`
5. Open a Pull Request.
